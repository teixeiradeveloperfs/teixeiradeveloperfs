## About

I'm a 23yo full-stack developer based in Salvador, Brazil. I build products end to end — interface, API, database and the infrastructure holding it all up. Started fixing computers at 14, wrote my first production code at 19, and led an agency's tech department at 22.

Today I run **AutomaGroup**, a technology company shipping subscription products and services for iGaming, sports betting and financial market operations. I care about the parts nobody sees: authorization models, encryption at rest, latency budgets, and test suites that actually run against a real database.

## Engineering
